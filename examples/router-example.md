# Worked example — "The Router Nobody Touches"

The reference production for this skill: one story, made in all three styles.
Storyboards: `router-storyboard-style-a-whiteboard.png` · `router-storyboard-style-a-color.png` (the Style A board after its colorize pass — identical drawing, color added) · `router-storyboard-style-b-color.png`

**Planning line** — Viewer identity: anyone whose home router has sat untouched for years. Mechanism (one only): the router's admin password is still the factory default, `admin`.

## Script package

```
TITLE: The Router Nobody Touches
STYLE: A or B (identical script — only the visuals change)

BEAT 1 — SHOCK
  Caption: A STRANGER USES YOUR WI-FI
  Narration: "Right now, a stranger is using this family's Wi-Fi — and they have no idea."
  Visual: Night. The family asleep; outside, a grinning stranger on a laptop, a dotted Wi-Fi line running from the family's router to his screen.

BEAT 2 — CAUSE
  Caption: NEVER TOUCHED IN 3 YEARS
  Narration: "Their router has sat in the corner for three years. Never restarted. Never updated. Never touched."
  Visual: The router on its shelf under dust and cobwebs, a calendar beside it reading 3 YEARS.

BEAT 3 — MECHANISM
  Caption: PASSWORD STILL admin
  Narration: "And its password? Still the one it came with: admin. Anyone can just… walk in."
  Visual: Extreme close-up of the router's sticker — PASSWORD: admin — circled twice in red, arrow pointing at it. The family small and worried at the edge.

BEAT 4 — PAYOFF
  Caption: ONE RESTART KICKS HIM OUT
  Narration: "One restart with a new password — and he's out. When did you last touch yours?"
  Visual: A hand pressing the router's reset button; the stranger staring at a dead laptop (red X); the family awake, thumbs up, a shield beside the router.
```

## What to notice

- The captions alone tell the whole story — test passed.
- The only number ("3 YEARS") is a story prop, not a statistic — nothing invented.
- The fix in Beat 4 is the genuinely correct first step (restart + change the default password), shown as one simple action.
- The same script produced both storyboards; Style A sells clarity, Style B sells warmth and detail. A channel can run a series in one style or test the same story in both.
- Next angles of the same mechanism: the CCTV camera still on its default password; the office printer; the smart TV that never got updated.
